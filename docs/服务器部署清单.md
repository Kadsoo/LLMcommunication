# 服务器部署清单（两台服务器到位后按序执行）

> 推荐直接跑一键脚本（幂等，失败早停）：
> `bash scripts/setup.sh`（环境+权重+冒烟），再 `LLM_MODEL=Qwen/Qwen3-4B bash scripts/run_eval.sh`（评测）。
> 下面是手动步骤，供脚本失败时排查对照。

## 0. 前置

- 两台服务器 A / B，可互相 ping 通（局域网内网 IP）
- 各 1 张 NVIDIA GPU（显存 >= 16GB 可跑 4B 量化；8GB 需 4bit）
- 系统建议 Ubuntu 22.04+，Python 3.10-3.12，CUDA >= 12.1

## 1. 拉代码（两台都做）

```bash
git clone https://github.com/Kadsoo/LLMcommunication.git
cd LLMcommunication
```

## 2. 装环境（两台都做）

```bash
python -m venv .venv && source .venv/bin/activate
pip install torch --index-url https://download.pytorch.org/whl/cu121
pip install transformers accelerate safetensors pyarrow gradio
```

## 3. 换 4B 模型（一处改动即可）

- `eval/compare.py`、`eval/kv_equiv.py`、`eval/delta_kv.py` 顶部的 `MODEL` 改为：

```python
MODEL = "Qwen/Qwen3-4B"  # 显存<16GB 时加 load_in_4bit 量化
```

## 4. 真跨机文本对话（Step4 复测）

- 服务器 B：`python transport/server_b.py`（监听 0.0.0.0:5101，代码里已绑定）
- 服务器 A：把 `transport/client_a.py` 的 `TcpTransport(port=5101, ...)` 改为
  `TcpTransport(host="<B的IP>", port=5101, ...)` 后运行
- 验证：A 的 a2 输出正常、B 的日志与 A 对得上

## 5. 4B 重跑 50 题对比（Step6-7 终测数据）

```bash
python eval/compare.py        # 50题 TOKEN vs KV，约 GPU 10-20 分钟
python eval/delta_kv.py       # Delta KV 压缩比（可选，出论文数据）
python demo/build_report.py   # 重新生成页面
```

## 6. 起 Web Demo

```bash
python demo/app.py            # 服务器 B 上起，0.0.0.0:7860
```

浏览器访问 `http://<B的IP>:7860`

## 7. 常见问题

- 显存不足：`AutoModelForCausalLM.from_pretrained(MODEL, load_in_4bit=True)`（需 `bitsandbytes`）
- KV 传输 `past_key_values` 类型不匹配：两端 transformers 版本必须一致（>=5.0 都是 DynamicCache）
- 端口不通：检查防火墙 `ufw allow 5101/tcp`、`ufw allow 7860/tcp`
